## Current limitations

They do not specifically document `/responses`. The successful real request establishes compatibility for this gateway and `gpt-oss:120b` Router workflow at verification time; it does not establish reliable specialist tool calling. Technical, Account, and live invoice follow-up remain pending. The user's SharedLLM Usage & Billing records show that `glm-5.3-flash` and `kimi-k2.6` requests reached Ollama Cloud and returned HTTP 401, while several `gpt-oss:120b` requests returned HTTP 200. This supports a model-specific upstream access problem, not a globally invalid SharedLLM key; the exact upstream cause is unknown. The Kimi row lists 270 tokens and $0.0003, but that is the dashboard's charge for a failed request, not a successful workflow. The ignored `.env` was restored to the last known working `gpt-oss:120b` setting. `openai-responses` is a separate provider path and remains unrun. Local SDK tracing is not the hosted OpenAI trace dashboard.
